# BiteLog

A simple calorie and macro tracker built for iPhone, with barcode scanning, a daily food diary, saved meals and recipes, weight tracking, and one-day-ahead logging for night-shift workers.

## Current status

This repository contains the current private web-app prototype. Profile and diary data are stored locally in the browser on the user's device.

## Features

- Calorie and macro targets
- Lean-bulk, maintenance, and weight-loss goal calculations
- Barcode scanning through Open Food Facts
- Daily food diary with tomorrow logging
- Saved meals and recipes
- Weight and water tracking
- Local backup and restore

## Run locally

Serve the `dist` directory from any static web server. Camera-based barcode scanning requires HTTPS or localhost.

## Important

Nutrition targets are estimates, not medical advice. Barcode data is community-maintained; verify serving sizes and nutrition against the product label.
